Privacy policy

Last updated: October 27, 2026

job-autofill is a personal tool used only by its owner, on the owner's own computer. This page describes what it does with Google user data.

What it accesses

  • Scope: https://www.googleapis.com/auth/gmail.readonly (read-only).
  • It searches the owner's mailbox for job-application email (for example from applicant tracking systems) from the last few days and reads those messages.
  • It never sends, deletes, moves, labels or changes any email.

How the data is used

  • Each message is classified on the owner's computer (application received, rejected, assessment, interview, offer, action needed) and matched to the owner's own list of applications.
  • The result (company, role, status, date, a short excerpt as evidence and the message id) is stored only in local files on the owner's computer.
  • The data is not sent to any server operated by this tool, not shared with or sold to anyone, and not used for advertising or to train models.

Storage and security

  • The OAuth refresh token is kept in the macOS Keychain of the owner's computer.
  • Requests go directly from the owner's computer to Google's Gmail API over HTTPS.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local files and the Keychain entry removes all stored data.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
